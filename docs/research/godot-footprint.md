# Godot 在本机的底座：常驻那扇窗要付多少

这一支自己的实测结果，2026-09 在本机量，问的是「这个程序站着不动时占多少」。

- **Godot 4.7.2 mono 空项目**（1280x720）：工作集 **199 MB**、**2 个进程**。这是 Keeper 的底座 —— 它一辈子常驻托盘，这一份是每时每刻都在付的固定成本。
- 「遮罩那些窗为什么在启动时就造好、而不是到点才造」不在这张卡里：那是取向，在 `docs/adr/0003-the-window-landing-wallpaper-input.md`；它靠的是这一条 —— 渲染器没能在 3 秒的淡入里冷启动，`fadeInMs` 的头几帧会拿去建窗而不是画斜坡，「淡入不许跳」当场就成了一句跳。

**可复测**：拿 `--check` 那一跑之外另起一版空项目，或直接把 Keeper 常驻起来看工作集。这两个数是本机一台机器的实测结果，换一块显卡、换一个 DPI 没重测过。
