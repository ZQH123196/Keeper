# 嘉靖的一天：**没有硬史料**，这一份是演绎重构

工单 06（`.scratch/archive/keeper-routine/issues/06-first-batch-presets.md`）。**2026-10-02 抓取。** 结论写在最前面：

> **嘉靖的日常作息没有任何硬史料。** 下面两条一手史料只支撑「他斋居、他修玄、有西苑这么个地方」
> 这三件**事实**，**不支撑任何一个具体时刻**。所以 `presets/嘉靖的一天.jsonc` 里**每一块都标「演绎重构」**，
> 包括那两块睡觉的。ADR-0005「考证的取向」把这一份点名为「不假装考证」。

## 一、查到的一手史料（两条，都实际抓过）

### 1. 他专门造了一间「斋居」用的屋子 —— 有确切年月

- 页面：`https://zh.wikisource.org/wiki/明世宗實錄/卷二`（经 MediaWiki API 取 `wikitext`）
- 读取日期 **2026-10-02**。
- 该卷开篇一行定年：**「嘉靖十三年甲午春正月戊戌朔」**（即 1534 年）。
- 卷内九月丙寅条原文：

  > 九月丙寅，初，上于文華殿後建九五齋恭默室，為祭祀齋居之所，至是訖。
  > 上命輔臣以詩紀其事，張孚敬、李時各上五言詩四章。

- **这一条证明**：嘉靖十三年（1534）九月，他在文华殿后建了一间**专供「祭祀斋居」的屋子**，
  建成那天还命辅臣作诗记之。**它证明「斋居」是这位皇帝亲自安排的、占一段正式时间的活动** ——
  仅此而已，它**没有说**他几点起、几点入斋、斋多久。

### 2. 西苑是他单独召大臣的地方；「世庙修玄」是实录自己的评语

- 页面：`https://zh.wikisource.org/wiki/明世宗實錄/卷三`（同上，API 取 wikitext）
- 读取日期 **2026-10-02**。
- 嘉靖二十九年（1550）一条：

  > 禮部尚書徐階因召對於西苑。上曰：「今事勢如此，奈何？」

  —— 大臣在**西苑**被召见，是实录里白纸黑字的场面。

- 同卷的馆臣按语（同为实录原文的一部分）：

  > 時世廟修玄，盛端明與顧可學皆以此祟顯。可學，燒煉服食，一異端耳，何足置之齒頰。

  ——「世庙」就是嘉靖；**「世廟修玄」是修《明实录》的馆臣对他的定性**。同卷另有真人邵元节
  （嘉靖十三年十月条）受宠出京的记载，呼应同一件事。

- **这两条证明**：`西苑` 是一个实有的、皇帝与大政要在那里单独见面的场所；`修玄` 是他身边长期在办的一件事。

## 二、为什么这份从头到尾是「演绎」—— 史料的体裁本身不记这些

`明實錄` 是**事件与奏章的记录**（「某日某条奏了什么、上批了什么」），**不是起居注**，更不是个人日程表。
嘉靖一朝没有留下逐时逐刻的起居记录可供复原。上面那两条是**在几十万字里搜到的、能落到「斋居/修玄/西苑」
这三个词上的**记录 —— 搜到的是活动**存在**，不是活动的**时刻**。

**所以规则定死**（模板里逐块照办）：

1. **每一块都标「演绎重构」**，包括睡眠块。没有例外。
2. 上面那三条事实**只用来定「一天的形状」，绝不用来定任何一个具体时刻**：
   - 「斋居是占一段正式时间的活动」→ 支撑**一整段连续的、被打断得很少的独处块**（不切碎成饭点/茶点）。
   - 「西苑是大政要单独见面的地方」→ 支撑**西苑单独成块**。
   - 「修玄」→ 支撑**修玄单独成块**。
3. 模板顶上的注释**明写**「演绎重构」四个字的依据是哪三条。
