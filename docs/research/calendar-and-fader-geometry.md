# 日历与遮罩的几何数：哪些是算术，哪些是这一版自己定的

本节全部取值定在 **1280x720** 的画布框上（不是 1920x1080），在当前这块屏（2560x1440 @125%）上验过。
绝对数的出处只有这一版自己，本节里凡写得出算术的都写成算术，写不出的都点明「绝对值无外部出处」。
这一节收的是**几何与取值的算术**；从屏幕上抓一帧再读回来的那一族（混色、首帧那六件事、活文档改一次
就挪窗）在 `docs/research/live-frame-measurements.md`，两边不抄同一发。

- **100% coverage 的格子**：七列，竖线落在 **1280/7 = 182.857** 的整数倍上（右边到 1279）—— 这条是算术。
  横线从 **y=52** 起每 **133.4** 一根，第五行正好收在 719。y=52 是 `MeasureGrid` 抬头一带取
  **7.2%** 的取整（720×0.072 = 51.84）；1792x966 那一发同一条 = 69（966×0.072 = 69.55）—— 两处都对得上，
  所以这条也是算术。**行距 133.4 不是算术**（(720−52)/5 = 133.6 才除得尽），那两根绝对值
  （52、133.4）是这一版取的数，没有外部出处。字号从格子高度推、不写死、下限夹 10
  （40% coverage 那一跑格子只有 53 px 高，15 号字比格子高 —— 那是这一支自己的跑，是量到的）。
- **格子的底是同一种黑换三档不透明度**：平日 `#939698`、周末那两列 `#76787B`、跨月 `#D9D9DA` ——
  这三个色值是**这一版取的，绝对值没有外部出处**。压白页反推 alpha ≈ **0.42 / 0.50 / 0.15** 是算术
  （1 − 各色通道均值/255：149.7/255 → 0.413，120.3/255 → 0.528，217.3/255 → 0.148），
  **所以颜色从来是定的，不是读出来的**。
- **`outline` 那一档一条线都没有**：在那张 1280x720 的画布框上，阈值 2 横扫 **y=396**、竖扫 **x=5**
  都读不到 —— 这两根行列号是那幅画布上的实测结果，绝对值无外部出处；「那一档 = 只有字」这个结论由这一版
  自己的渲染验过，它和 wallpaper 共用同一套真控件，只差 `Layout.Fills` 一旗。几何一格不差是验过的，
  所以 `_draw` **为几何不必写**；设计文档 `docs/design/calendar.md`「三档样式」那一节里那句「bare rules」要照做，欠的是执行加一帧判据 —— 见
  `.scratch/keeper-debt/issues/09`（用自绘换那几条控件画不出的线，这条边界本身在 ADR-0001「界面默认用真控件」那一节）。
- **遮罩那四组比例是这一版取的值**：`ClockRatio 0.131 / RowRatio 0.043 / SmallRatio 0.028 /
  BoxRatio 0.0264`。推导曾经按 720 高的画布框写成行数：钟那五个数字 68 行 = 9.44%、格子那排 19 行 =
  2.64%、清单每行 29 行 = 4.03% —— 行数与百分比互推是算术（68/720 = 0.0944），但**行数本身没有外部
  出处**。屏高是物理像素，所以比例**不再乘 DPI**，留 DPI 那一乘的只有「再小就读不出来」那根下限。
  这三项被本版取值换掉的旧设定数是 5.6% / 1.7% / 0.97%，绝对值无外部出处，留在这儿仅作对照。
- **淡入实测**：3 秒 269 帧、单帧最大跳 1.5 级；举起约一帧时 alpha=0.0000。中间帧
  `fader-ramp-40.png` 读到 `alpha=0.278`、`fader-ramp-75.png` 读到 `alpha=0.518`（这两张抓帧
  2026-11-08 已移出仓库；读数是当时从那两张图读的）。**抓一帧 2560x1440 自己会撑出一个 alpha 大跳**（平时单帧
  0.004–0.008，抓帧之后读到 0.0360/0.0374），所以「淡入不许跳步」不能拿带抓帧的那一跑判。

- **把磁盘上已有的用户配置当证据之前先看日期**：`%APPDATA%\Keeper\settings.jsonc` 是早几轮
  留下的文档 —— 无注释、缺 `flow`/`flows`/`dismissHoldMs`/`maxRetryDelayMs`/`calendar`/`schemaVersion`，且
  `blockWhenFullscreen` 被他改成 `false`。别拿它当「默认值长什么样」的证据。硬规矩一条：属性和声明表里
  不许各写一份默认值；`SelfCheck()` 抓到过一个真 bug —— `flow` 是自由文本，若按可选值校验，
  用户自己起的 flow 名会被抹成默认。
