# 休息流程是一张表，步是表里的行

休息流程的形状。这一份只写这张表的形状与机制。
产品行为在契约 `.scratch/keeper-contract/spec.md`「行为不变量」那一节。

## 字段

这一步形状来自声明表，不是代码摘录。

| 字段 | 含义 |
| --- | --- |
| `ms` | 淡入落定之后这一步站多久。最后一步写 `0` = 一直站到别的事结束它；写在前面任何一步 = 淡一到就把下一步接上。 |
| `dismissible` | 这一步里只来一下输入还赶不赶得走淡入。键盘和鼠标都算数。 |
| `layout` | 这一步屏上那一整份：哪些控件、各在哪、各占多大、谁盖住谁。形状在 `fader-layout.md`。 |
| `sound` | 这一步放不放那个声音文件。 |

**`content` 和 `text` 两个成员 2026-10-06 退休** —— 文字成了布局里的一个控件，
一步能摆任意多个；图也是。这两个名字在老配置里照旧**认得**，只是不再变成控件。

**`interactive` 2026-10-10 整条退休** —— 它主张「这一步收走鼠标」，而收鼠标那一扇窗
（点击窗）一起拆掉了。现在「点得到」归全局钩子（见 `hit-testing.md`），
这一步不再有「收鼠标」这一档。

## 出厂三行

- **`fadetop`** —— 只有淡入本身。
- **`todoList`** —— **一步**：默认布局上时钟和那一步的文字在中间、清单和那颗钮在侧面；
  只来一下输入无效，遮罩完全浮现之后清单才点得动，直到时长走完 / 人走开 ——
  那两者算休息过；**按下提前结束和挥散同路，记跳过**。
- **`pomodoro`** —— 淡入之后是五分钟短休。只来一下输入无效；
  专注段多长不在这张表里 —— 它是那个键的事（见 `pomodoro.md`）。

用户能新增行、改名、加步删步挪步。名字不认识、或一行步都没有，读作 `fadetop`。

## 时间块名那个控件是布局里唯一动态的一个

它显示的是按作息表现在所处的时间块的名字。没有作息表、或此刻不在任何块里，
它空着。
