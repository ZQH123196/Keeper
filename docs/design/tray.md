# 托盘与开机启动

托盘那一族与开机启动。这一份只写形状与机制。
产品行为在契约 `.scratch/keeper-contract/spec.md`「行为不变量」那一节。

## 托盘没有引擎 API

`Shell_NotifyIcon` 从 C# 调。三颗图标状态（空闲 / 淡入中 / 自动淡入已关），
左键切预览、右键出菜单（里面有一颗番茄钟）。

**一颗图标一个进程**，靠内核持有的具名互斥体撑住。

**菜单是每次右键现做的**，所以勾问出来的是当下那一刻的意图，
没有一份要刷的缓存。

## 顶上第一行报「这一段还差多久到线」

摆的是**菜单里的第一项**，在「显示遮罩」上面。写的是**这一段**还差多久到线 ——
**2026-10-21 所有者定夺之后触发按现实时间走**，所以它报的就是触发量的那个数：
从「这一段从哪一刻起算」到触发门槛还差多少。到线报 `0:00`。

（原来这一行写的是「连续输入还差多久到线」。那是旧口径 ——
触发量的是连续输入。实测结果在 [`../research/continuous-streak-gap.md`](../research/continuous-streak-gap.md)。）

它和「时间块名」「勿扰中」那两行同款：**点不动、也不递命令 id**，
底下的命令项照旧能触发。

**自动淡入关着 / 番茄钟在跑 / 遮罩已经抬着，这三档那一行整个不出现** ——
不是摆一个空着的一行，项数差一。

**写法**：不到一小时 `m:ss`，过了一小时 `hh:mm:ss` —— 休息最长能排到两小时，
`90:00` 读不出那是九十分钟。

## 开机启动：意图在文档里，注册表是它的效果

- 托盘里一颗「开机自动启动」：按一下切过来，再按一下切过去，勾跟着当下的意图走。
  设置窗「系统」那一格是同一个键的同一条路，两个入口指的是一件事。
- 意图**只有 `autostart` 这一个键**，**方向是单向的** —— 程序不反过来读注册表决定行为。
  那样会有两个都能说了算的地方。
- **托盘那一下不自己写注册表。** 它改的是那一个键，然后走启动时和设置窗刚应用时
  **同一个**对账动作。注册表是那一个动作的效果，不是第二条路。
- **开机启动不跟着生活模式走**：托盘这一下切的是活的那一份，不落进任何一份生活模式。
