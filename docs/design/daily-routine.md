# 作息表是一张按现实时间走的表，时间块是表里的行

按现实时间走的第二路触发。这一份只写这张表的形状与机制。
产品行为在契约 `.scratch/keeper-contract/spec.md`「行为不变量」那一节。

## 作息表是配置不是记录

和休息流程表**并列**的一张表，一行是一个**时间块**。块的字段形状住在声明表
（这份文档不抄键的清单），这一份只说语义。

## 现实时间只从 App 一处进来

`App` 每帧开头刷新一个缓存的时刻（产品按 0.2 秒采样）：有测量程序的覆盖就用覆盖，
否则问一次真钟。同一帧里所有要现实时间的地方读的都是它，不再各问各的 ——
一次读从消费点提前到帧首，分钟边界最多提前几毫秒被看到，而产品本来就每 0.2 秒才看一次。

按需要深度分两种口子：

- 只用分钟的 module 收分钟：`Scheduler.Step(…, int wallMinute)` 必填，这一族只做
  算术和判定；托盘「时间块」那一行收 `Routine.MinuteOfDay` 算出的分钟。
- 需要整个时刻的收时刻：`Dnd.Of` / `Tray.DndWhy` 收调用方给的 `DateTime`；
  `Fader` 构造收 `Func<DateTime>`，块名和时钟都问它（见 `fader-window.md`）。

自检和测量程序递自己的假时刻。全仓问真钟的只剩 `App` 两处：帧首那一句刷新，
和字段初值（避免首帧之前托盘菜单读到默认值）。

## 一块有起止时刻

止不晚于起，它就是**跨午夜**的那一块（22:30 → 06:30 是一夜的睡眠，一块，不是两块）。

「现在在哪个块」**用现实时间做纯算术**推出 —— **无状态，不新增记录**。
程序没在跑、机器在睡而错过的块到点，**不补抬**。

## 一块有名字和种类

名字是托盘提示和遮罩上原样显示的那几个字。种类里**唯一带行为语义的是「睡眠」**：
标着「睡眠」的块里一切触发都不抬遮罩（自动淡入、番茄钟那一轮、别的块的到点），
直到块走完；番茄钟自己的钟照跑，到点没抬的那一轮在块走完后抬 ——
和「全屏一让就抬」同一条款。

其余种类（专注 / 休息 / 食事 / 运动……）**只是标签**，给块名显示和将来的主题化用，
**不带任何默认行为**。

## 块内行为逐块写，不从种类推

到点抬不抬遮罩、到点走哪一行休息流程（没写就走「这次休息走哪一条」指着的那一行）、
活动提醒在这一块里让不让位 —— 都是块里的键，默认值由声明表给。

预设生活模式要哪种过法，就在它那份文档里写哪种值 ——
**不为任何种类立产品级的默认政策**。

## 到点那一次抬遮罩不是休息

不进休息记录，所以健康度那一读法不动 —— 它是块切换的一次「光的提示」，
挥散或走完都随意。走的仍是休息流程那套机器（哪一行由块定），
**不为作息表发明第二种弹窗**。

## 谁管它

到点抬遮罩受 `autoFade` 和 `blockWhenFullscreen` 管（独占全屏时不抬，让开之后也不补 ——
时刻过了就是过了）。作息表整个关掉时，块的行为全部回到现状
（输入触发和番茄钟各按各的老规矩）。

## 托盘提示那一行

显示当前时间块的名字（和番茄钟剩余时长那一行同款做法）；
没有作息表、或此刻不在任何块里，这一行不出现。

## 键归「作息」这一域

不是系统 → **全部进生活模式**（判据仍是域本身，见 `life-mode.md`）。
设置窗顶部的分格标签多一格「作息」，和其余几格平级；编辑器照休息流程编辑器那个模式搭
（真控件、不运行期生成界面）。

界面上走人话单位：时刻就是时刻、分钟就是分钟，毫秒不出现。

## 一个生活模式内部的块切换，不是生活模式之间的自动切换

生活模式之间的自动切换仍不做。
